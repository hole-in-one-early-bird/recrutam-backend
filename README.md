# RECRUTAM

진로를 고민하는 취준생과 커리어 전환을 희망하는 직장인을 위해 나에게 맞는 AI 맞춤형 커리어 추천 서비스를 제공합니다.

나의 **개인 정보**와 **취미, 경험**까지 모두 반영된 분석을 통해 어떤 진로 검사보다도 **간편하고 정확한 커리어**를 추천받을 수 있습니다.

> Step 1. 나의 개인정보와 관심 분야를 입력해요. <br>
Step 2. 더 정확한 분석을 위해 나의 성향에 맞는 키워드를 선택해요. <br>
Step 3. 리쿠르탐이 추천하는 맞춤 커리어를 제공받아요. <br>
Step 4. 챗봇과 대화하며 더 많은 정보를 얻을 수 있어요.
>
